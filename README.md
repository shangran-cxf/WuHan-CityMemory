## 1. 项目概述

「武汉 · 城市记忆」是一个以**长江时间轴**为主线的单页文化展示网站。
页面以武汉三镇（汉口、汉阳、武昌）与长江、汉江的轮廓动画作为封面序章，
随后引导用户沿长江顺流而下，依次穿行武汉城市发展史上的 **8 个关键节点**，
通过真实历史照片与史实注解，呈现一座江城从商代盘龙城到当代光谷的记忆长卷。

### 1.1 项目背景

- **主题**：武汉城市历史与文化记忆
- **形式**：单页交互式网页（无后端、无框架）
- **受众**：课程小组成员、任课教师、对武汉城市文化感兴趣的读者
- **载体**：本地静态服务器预览，可扩展部署至 GitHub Pages 等静态托管平台

### 1.2 核心叙事

封面序章（武汉轮廓 + 长江穿流）→ 沿长江时间轴顺流而下 → 8 个历史节点 → 每个节点配真实照片与史实注解 → 1957 长江大桥今昔对比滑块 → 结尾回到"今天"。

## 3. 功能需求

### 3.1 封面序章动画（必选）

- 两岸白色蜿蜒岸线自上游向下游**描边生长**，上下缘淡出画面。
- 长江主河道（蓝色带）随后**穿流而下**，汉江自西侧汇入。
- 汉口、汉阳、武昌**三镇依次点亮**。
- 主标题 **"武汉 · 城市记忆"** 与副标题"沿时间而行"浮现。
- 底部出现滚动提示。
- 触发切入主页面的方式：滚轮向下 / 手机上滑 / 点击提示 / 按 Enter 或空格。
- 切入时加锁防止重复触发。

### 3.2 长江时间轴导航（必选）

- 以 SVG 绘制长江蜿蜒曲线作为主时间轴。
- 8 个节点沿河道均匀分布（位置比例 `[0.03, 0.164, 0.299, 0.433, 0.567, 0.701, 0.836, 0.97]`）。
- 已游览节点以实线高亮，形成进度条效果。
- 当前节点显示年份 + 标题。

### 3.3 节点内容展示（必选）

- 每个节点展示：年份、主题、史实注解（底部展签条）。
- 主图展示当前照片，配画面注解与图片来源（credit）。
- 左右预览图提示相邻节点。
- 图片加载失败时回退至占位图（`assets/archive-river.svg`）。

### 3.4 多种导航方式（必选）

| 方式 | 行为 |
| --- | --- |
| 鼠标滚轮 | 累积阈值 80px 防抖，切换上一/下一节点 |
| 拖拽 | 在时间轴上拖拽切换 |
| 点击节点 | 直接跳转至指定节点 |
| 键盘 | ← → ↑ ↓ 切换，Home / End 跳首尾 |

### 3.5 1957 今昔对比滑块（必选）

- 针对 1957 长江大桥节点，提供可拖拽滑块对比历史照片与现代照片。
- 滑块左右移动实时裁剪上层图片。

### 3.6 响应式与可访问性（必选）

- 桌面端：左右分栏布局。
- 移动端（≤700px）：底部横向年份条。
- 支持 `prefers-reduced-motion`（降低动画强度）。
- 关键元素含 `aria-label`，语义化标签。

### 3.7 节点清单（8 个）

| # | 年份 | 主题 | 照片数 |
| --- | --- | --- | --- |
| 1 | 约前 14 世纪 | 盘龙城 | 3 |
| 2 | 1861 | 汉口开埠 | 3 |
| 3 | 1911 | 辛亥首义 | 3 |
| 4 | 1949 | 武汉解放 | 2 |
| 5 | 1957 | 长江大桥 | 3 |
| 6 | 1998 | 守护江城 | 3 |
| 7 | 2020 | 春天重启 | 3 |
| 8 | 今天 | 向新而行 | 3 |

## 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 首屏动画 ≤ 4s 完成；图片懒加载，单张 ≤ 500KB |
| 兼容性 | Chrome / Edge / Firefox 最新版；移动端 Safari / Chrome |
| 可访问性 | `prefers-reduced-motion` 支持、aria 标签、键盘可达 |
| 鲁棒性 | 图片 onerror 回退；切入动画加锁防重复 |
| 可维护性 | 数据（`memories` 数组）与视图分离，增删节点仅改数据 |
| 版权合规 | 所有照片标注来源（credit），优先使用公有领域或已授权素材 |

## 5. 数据与素材规格

### 5.1 数据结构

每个记忆节点采用如下结构（定义于 `script.js`）：

```js
{
  year: '1861',                       // 年份标签
  title: '汉口开埠',                    // 主题
  fact: '史实说明文字...',               // 底部展签条
  images: [
    ['./assets/photos/1861-1.jpg', '画面注解', '图源 credit'],
  ],
}
```

### 5.2 图片素材规范

- 格式：JPG（已裁剪水印 / 黑边）
- 命名：`<节点标识>-<序号>.jpg`，如 `1861-1.jpg`、`panlongcheng-1.jpg`、`today-1.jpg`
- 路径：`assets/photos/`
- 每张图必须附带：画面注解 + 来源（credit）

### 5.3 技术栈

- HTML5（语义化标签）
- CSS3（Grid / Flex / 动画 / 媒体查询）
- 原生 JavaScript（ES6+，无框架）
- SVG（长江路径、封面地图、动画路径）

## 6. 团队分工

> 团队共 **5 人**：用户本人（网站开发负责人）+ **4 位队友**。
> 后续工作共 **5 项**，分配如下。

### 6.1 分工总表

| 序号 | 任务 | 负责人 | 角色定位 | 核心交付物 |
| --- | --- | --- | --- | --- |
| 1 | 网站开发 + 动画切换设计 | * | 开发负责人 | 可运行网站、封面动画、节点切换、对比滑块 |
| 2 | 做 PPT | 队友 A | 汇报视觉设计 | 小组汇报用 PPT 终稿 |
| 3 | 文字分析 | 队友 B | 内容主笔 | 8 节点史实注解、汇报讲稿、展签文案 |
| 4 | 小组汇报 | 队友 C | 主讲人 | 现场汇报、答辩问答 |
| 5 | 寻找照片 | 队友 D | 素材采集 | 23 张真实照片 + 来源清单 |

> 说明："动画切换设计"由用户本人主导——因为网站的封面动画与节点切换效果由开发者直接实现，设计者与实现者合一可最高效地保证效果落地。如队友有余力，可协助提出动画节奏与视觉方案的优化建议。

### 6.2 各任务详细职责

#### 任务 1：网站开发 + 动画切换设计

- 搭建单页网站骨架（HTML / CSS / JS）。
- 实现封面序章动画：岸线描边 → 长江穿流 → 三镇点亮 → 标题浮现。
- 实现长江时间轴与 8 节点定位（`getPointAtLength`）。
- 实现四种导航方式（滚轮 / 拖拽 / 点击 / 键盘）。
- 实现 1957 今昔对比滑块。
- 响应式适配与可访问性处理。
- 与队友 B（文字）、队友 D（照片）对接数据与素材。

#### 任务 2：做 PPT

- 围绕"武汉 · 城市记忆"主题设计汇报 PPT。
- 内容结构：项目背景 → 设计思路 → 功能展示 → 技术实现 → 总结。
- 嵌入网站截图 / 录屏动图，展示封面动画与节点切换效果。
- 风格与网站视觉统一（水墨 / 江水蓝 / 宣纸色）。
- 与队友 C（汇报）协作，确保页面顺序与讲稿一致。

#### 任务 3：文字分析

- 为 8 个节点撰写史实注解（`fact` 字段），要求准确、简洁、有温度。
- 为每张照片撰写画面注解。
- 整理各节点的历史背景资料，形成文字分析报告。
- 撰写小组汇报讲稿（配合队友 C）。
- 将文案以结构化形式交付给用户本人，方便录入 `memories` 数组。

#### 任务 4：小组汇报

- 担任小组汇报主讲人，全程讲解。
- 熟悉网站所有功能与 8 个节点内容，能流畅演示。
- 准备答辩问答（可能涉及设计思路、技术实现、史料来源等）。
- 与队友 A（PPT）、队友 B（讲稿）紧密配合，提前排练。
- 控制汇报时长，确保在规定时间内完成。

#### 任务 5：寻找照片

- 为 8 个节点共 23 张照片寻找合适的真实历史影像。
- 来源优先：公有领域（维基共享资源）、官方媒体（新华社、长江日报、人民画报）、博物馆（盘龙城博物院）、现代摄影授权图。
- 每张照片须记录：文件名、画面注解、来源（credit）。
- 对有水印 / 黑边的图片进行裁剪处理后转为 JPG。
- 按命名规范存入 `assets/photos/`，并提供来源清单。

## 9. 验收标准

### 9.1 网站验收

- [ ] 封面动画完整播放：岸线 → 长江 → 三镇 → 标题，无黑屏、无错位。
- [ ] 切入主页面方式全部可用：滚轮 / 上滑 / 点击 / 键盘。
- [ ] 8 个节点均可通过 4 种导航方式切换，无卡死。
- [ ] 每个节点显示正确的年份、标题、史实注解、照片与来源。
- [ ] 1957 对比滑块拖拽流畅，左右对比正确。
- [ ] 移动端（≤700px）布局正常，底部年份条可用。
- [ ] 图片加载失败时显示回退图，不出现裂图。
- [ ] `prefers-reduced-motion` 下动画减弱但不影响功能。

### 9.2 素材验收

- [ ] 23 张照片全部就位，命名规范，无水印 / 黑边。
- [ ] 每张照片附画面注解与来源（credit）。
- [ ] 史实注解准确、无事实错误。

### 9.3 汇报验收

- [ ] PPT 结构完整、风格统一、嵌入网站效果展示。
- [ ] 讲稿与 PPT 顺序一致，时长可控。
- [ ] 主讲人能流畅演示并回答常见问题。
